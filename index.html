Write-Up

1. What have you done so far?

So far, we have the global aerosol trends using Aerosol Optical Depth (AOD) linked with clicking a region on the map and the slider. Right now we are using NASA's MODIS Aqua satellite data for now as our main dataset to measure aerosol concentrations. We created an interactive global map using a Natural Earth projection and added a layer on top of it to display AOD measurements across different regions which allows you to click on individual countries and view their aerosol trends.

We have a colour scale to show the different AOD values, as well as the slider. We also added buttons for filtering between different aerosol sources, including dust, wildfire smoke, and pollution, which highlight the corresponding regions on the map, but this can be expanded upon.

2. What will be the most challenging of your project to design and why?

The most challenging part of our project will probably be showing all the changes in aerosol concentrations across different regions and time periods through AOD (Aerosol Optical Depth) on the map, since there are a lot of things working all at once. Since we want users to be able to filter between aerosol sources (Dust, Wildfiresmoke, Pollution), change the year with a slider, and select countries/regions to explore their individual trends with a plot on the side, as well as zoom in on the map to have a more detailed view, which requires multiple interactions to work together at once.

We will also need to determine how to represent different aerosol sources accurately, since what we originally wanted to do with just Aerosol Optical Depth only measures aerosol concentration but does not directly identify whether particles come from dust, wildfire smoke, or pollution, so we need to align that data set with the individual aerosol types from another dataset. Another challenge will be when adding the hover on top of the map and balancing the amount of information displayed to not overcrowd the user with information but provide the user with enough information to be useful with making the visualization understandable and easy to navigate will also be important for our design.
